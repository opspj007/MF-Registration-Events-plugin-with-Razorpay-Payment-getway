# Mahashankh Event & Talent Registration Manager

## Install
1. Zip the `mah-event-registration` folder.
2. WordPress Admin → Plugins → Add New → Upload Plugin.
3. Activate.
4. Create events under **Mah Registration → Events**.
5. Create a page with `[mah_registration]`.
6. Create an events page with `[mah_events]`.

## Current version
1.0.0

## Included
- Model, Dancer, Singer, Fashion Designer, Makeup Artist, Sponsor and Brand registration categories
- Event creation
- Registration database
- Admin registration list
- Free registration support (fee 0)
- Secure REST registration endpoint with WP nonce
- Basic email confirmation
- Responsive frontend
- Registration IDs

## Razorpay
The database and payment architecture includes a payment table, but **live Razorpay checkout/signature/webhook integration is not enabled in this starter build**. Configure and test Razorpay server-side verification before production use.
